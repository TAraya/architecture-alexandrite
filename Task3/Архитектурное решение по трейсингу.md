## Архитектурное решение по трейсингу

Схема в формате drawio находится в корне репозитория.

### Подсистемы для настройки трейсинга

Приоритетными подсистемами для настройки трейсинга видятся те системы, в которых наиболее вероятны ошибки:
- CRM
- MES
- онлайн-магазин

Данные трейсинга:
- идентификаторы заказов
- идентификаторы пользователей, в т.ч. операторов
- временные метки изменения сущностей

### Мотивация

- ускорение поиска причин ошибок и инцидентов
- ускорение исправления дефектов
- повышение стабильности работы сиситемы
- уменьшение бизнес-потерь, например, от несвоевременно выполненных заказов
- повышение лояльности клиентов, остановка оттока клиентов

### Предлагаемое решение

![text](../jewerly_c4_model.drawio.png)

В сиситеме используются крайне популярные технологии - Java SpringBoot и .net, предлагающие широкие возможности интеграции с OpenTelemetry. В качестве инструмента предлагается использовать наиболее популярное решение - Jaeger.

### Аспекты безопасности

Доступ к данным трейсинга возможен только для авторизованных пользователей системы с соответствующей ролью.
